# Práctica RA5 · c+d — Big Data e IA

## 1) Caso
- **Sistema:** Plataforma de recomendación de productos en un e-commerce  
- **Contexto:** Una tienda online analiza el comportamiento de sus usuarios para recomendar productos personalizados y aumentar ventas.

---

## 2) Conceptos
- **Big Data:** Conjunto de datos masivos que no pueden ser gestionados con herramientas tradicionales debido a su tamaño, velocidad y complejidad.  
- **Análisis de datos:** Proceso de inspeccionar, limpiar y transformar datos para obtener información útil.  
- **Machine Learning:** Rama de la IA que permite a los sistemas aprender automáticamente a partir de datos sin ser programados explícitamente.  
- **Deep Learning:** Subcampo del Machine Learning basado en redes neuronales profundas que permite analizar datos complejos como imágenes, texto o audio.  
- **IA (Inteligencia Artificial):** Conjunto de tecnologías que permiten a las máquinas simular inteligencia humana (decidir, predecir, automatizar).

---

## 3) Relación
Los datos masivos (Big Data) se recogen y procesan. Luego se analizan para extraer patrones.  
Estos patrones se utilizan para entrenar modelos de Machine Learning o Deep Learning.  
Finalmente, la IA usa estos modelos para tomar decisiones automatizadas.

---

## 4) Pipeline
**Datos masivos → Procesamiento → Análisis → Modelo ML/DL → IA → Decisión**

1. Recolección de datos de usuarios  
2. Procesamiento y almacenamiento  
3. Análisis para encontrar patrones  
4. Entrenamiento de modelos ML/DL  
5. Implementación en un sistema de IA  
6. Toma de decisiones (recomendaciones)

---

## 5) 5V del Big Data
- **Volumen:** Grandes cantidades de datos (millones de usuarios y productos)  
- **Velocidad:** Datos generados en tiempo real (clics, compras)  
- **Variedad:** Datos estructurados (ventas) y no estructurados (reseñas)  
- **Veracidad:** Calidad y fiabilidad de los datos  
- **Valor:** Información útil para mejorar ventas y experiencia del usuario  

---

## 6) Ejemplo aplicado
- **Datos:** Historial de compras, clics, búsquedas, valoraciones  
- **Análisis:** Identificación de patrones de comportamiento  
- **Modelo:** Sistema de recomendación basado en Machine Learning  
- **Decisión:** Mostrar productos personalizados al usuario
